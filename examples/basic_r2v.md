# Basic R2V Example

## Input

```text
生成方式：MiniMax H3 Reference to Video
動画尺：10秒

参照画像1：
20代後半の日本人女性のスタイルシート

参照画像2：
縞猫のスタイルシート

参照画像3：
雨の夜のワンルーム。
部屋全体の配置やベランダの位置関係が分かるスタイルシート。

シーン：
一人暮らしの女性の部屋に、雨でびしょ濡れになった縞猫がベランダから迷い込んでくる。
猫が部屋に入ってくるとき、一度だけ小さく鳴く。
女性は猫に気づき、濡れた身体をタオルで優しく拭いてあげる。
その後、女性は猫に餌を与える。

セリフなし。
ナレーションなし。

BGM：
穏やかで、ほっこりした雰囲気の優しいインストゥルメンタルBGM。

Purpose

This example demonstrates a basic MiniMax H3 Reference-to-Video prompt request using:

one character reference
one environment reference
a simple 10-second action
no dialogue
no narration

The generated output should follow the required six-section format.
