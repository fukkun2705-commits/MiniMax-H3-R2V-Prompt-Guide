# Multi-Subject R2V Example

## Input

```text
生成方式：MiniMax H3 Reference to Video
動画尺：10秒

参照画像1：
20代後半の日本人女性Aのスタイルシート

参照画像2：
30代前半の日本人女性Bのスタイルシート

参照画像3：
朝のカフェ店内

シーン：
女性Aは窓側の席に座ってコーヒーを飲んでいる。
女性Bは店内奥から歩いてきて女性Aを見つける。
女性Bは少し驚いた表情を見せたあと、
女性Aの向かいの席に座る。

女性Aは席を立たない。
女性Bは女性Aの席と入れ替わらない。
2人の顔、髪型、服装を混同しない。

セリフなし。
ナレーションなし。
BGMなし。
Purpose

This example demonstrates a multi-subject MiniMax H3 Reference-to-Video prompt request.

The generated prompt should:

define woman A and woman B as separate subjects
preserve each woman's facial identity, hairstyle, clothing, and body proportions
keep woman A seated at the window-side seat
have woman B approach from deeper inside the café
have woman B sit only in the seat opposite woman A
prevent identity mixing, face swapping, hairstyle swapping, clothing swapping, or seat-position swapping
add no dialogue, narration, or background music

The generated output should follow the required six-section format.
